Quicksort is a divide-and-conquer algorithm that picks a pivot element, partitions the remaining elements into those less than and those greater than the pivot, and then recursively sorts each partition. Its average-case running time is O(n log n), but a poor pivot choice, such as always picking the first element on already-sorted input, degrades it to O(n squared) in the worst case, which is why practical implementations often pick a random or median-of-three pivot.

Merge sort instead splits the array in half repeatedly until each piece has a single element, then merges the pieces back together in sorted order. Because the merge step processes elements in order without ever swapping equal elements past one another, merge sort is stable, and because splitting and merging both take predictable time regardless of the input's initial order, merge sort guarantees O(n log n) performance even in the worst case, at the cost of needing extra memory for the merge step.
