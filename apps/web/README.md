# VoxMind — Frontend

React + TypeScript + Vite. See the [root README](../../README.md) and [docs/development.md](../../docs/development.md) for setup, environment variables, and commands.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to :8000
npm run build    # type-check + production build
npx vitest run   # test suite
npx oxlint       # lint
```
