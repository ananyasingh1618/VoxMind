Reliable delivery in TCP begins with the three-way handshake: the client sends a SYN segment carrying an initial sequence number, the server replies with a SYN-ACK acknowledging that sequence number and proposing its own, and the client finishes with an ACK. Only after this exchange completes do the two endpoints consider the connection established, and every byte sent afterward is tracked with sequence numbers and acknowledgments so that lost or reordered segments can be detected and retransmitted.

Addressing and routing sit one layer below, at the IP layer. Every device on a network is assigned an IP address, and routers forward packets toward their destination by comparing the destination address against entries in a routing table, typically choosing the most specific matching route. Because IP addresses are hierarchical, a router only needs to know the next hop toward a block of addresses rather than the exact path to every individual host, which is what allows the global internet to scale to billions of devices.
